This is an early-stage project.
Any feedback is very welcome.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To test the production build (static export, same as what deploys to GitHub Pages):

```bash
npm run build
npx serve out
```
